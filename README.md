# pdfanonym

Free PDF tools that run **entirely in your browser**: your files are never uploaded.
Live at **[pdfanonym.com](https://pdfanonym.com)**, in English, French, German, Spanish, Italian and Portuguese.

## What it does

- **Real redaction**: marked text is removed from the page content (MuPDF redaction annotations), not hidden under a black box. Copy, search and text extraction return nothing.
- **Anonymization**: detects emails, phone numbers, IBANs (mod 97), card numbers (Luhn), French social security numbers, IP addresses and names after a title, then redacts them.
- **Metadata**: shows and removes or edits author, title, software, dates, XMP, comments, attachments and JavaScript.
- **Pages**: merge, delete, extract, rotate, reorder.
- **Edit**: add text, draw a signature, watermark, page numbers.
- **Convert**: compress (image downsampling), vector grayscale that keeps text selectable, PDF to JPG/PNG, images to PDF.
- **Security**: AES-256 password protection, unlock (with the password).

## How it works

- PDF engine: [MuPDF.js](https://github.com/ArtifexSoftware/mupdf.js) (WebAssembly), loaded from the same origin.
- No backend for documents. A strict Content-Security-Policy (`connect-src 'self'`) prevents the page from sending data to any other host.
- Static site generated by `build.py` (Jinja2 templates + one YAML file per language in `content/`).
- `functions/` contains the optional licence service for the paid Pro features (Cloudflare Pages Functions, Stripe Checkout, ECDSA-signed licence keys verified locally in the browser). It never receives files.

## Run it locally

```bash
pip install jinja2 pyyaml markdown
python3 build.py        # generates dist/
python3 serve_dev.py    # http://127.0.0.1:8811 with the production CSP
```
